Embedded Checkout Demo

在您的网站中嵌入 HydraPay 收银台 — 三步接入

接入步骤

1页面引入 SDK
2创建 Checkout Session（API）
3调用 HydraPay.checkout.create()

商户通过 API POST /v1/checkout/sessions 创建 session，拿到 session_id 后在页面中调用 SDK。

代码示例

<script src="https://your-domain.com/sdk/hydra-pay.js"></script>
<script>
HydraPay.checkout.create({
  sessionId: 'your-session-id',
  container: '#checkout',
  onSuccess: function(data) {
    console.log('支付成功', data);
  },
  onCancel: function(data) {
    console.log('用户取消', data);
  },
  onError: function(data) {
    console.log('支付错误', data);
  }
});
</script>
